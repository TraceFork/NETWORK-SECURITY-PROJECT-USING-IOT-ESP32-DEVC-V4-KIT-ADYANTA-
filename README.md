# NETWORK-SECURITY-PROJECT-USING-IOT-ESP32-DEVC-V4-KIT-ADYANTA-
IoT-based Wi-Fi network scanner using ESP32 DevC V4 (Adyanta). Detects nearby networks and displays SSID, MAC address, signal strength, and security status (Open, Secured, Unknown, Duplicate). Useful for ethical testing, Wi-Fi mapping, and network security analysis. For educational use only.
